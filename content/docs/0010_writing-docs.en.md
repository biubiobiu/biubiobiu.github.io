## Documents and blog posts

Document pages focus on content. They omit the blog cover, author profile, publication date, tags, and sharing controls.

## Add a document

Create a Markdown file under `content/docs/`, add its title, slug, weight, and `menu.docs` configuration, then write the document body in Markdown.

## Navigation

Use Markdown headings to generate the table of contents on the right. The `menu.docs` fields control the document tree on the left.
