HunyuanImage-3.0-Instruct 网络结构深度解析

统一自回归多模态模型：一个 80B（激活 13B）MoE Transformer 同时当「语言模型」和「扩散模型」· 贯穿示例：文本指令（可带 1 张参考图）→ 1024×1024 生成图 · 依据推理代码 hunyuan_image_3/ 与官方 checkpoint config 整理
读图主线：所有条件都变成 token 塞进同一条序列——文本查表、参考图兵分两路（ViT 给语义、VAE 给像素）、噪声画布经 UNetDown 变 token、时间步也占一个 token 位。80B MoE 主干对这条序列做一次前向：文本位置走 lm_head 出文字，图像位置走 UNetUp 出「修改方向」v̂，循环 50 步后 VAE Decoder 一次性译回像素。主干里没有 AdaLN、没有 cross-attention——条件注入完全是 LLM 式的 in-context；时间步的「调制」只藏在出入口的 UNetDown / UNetUp 里。

HunyuanImage-3.0-Instruct 完整数据流。五路输入（文本 / 参考图 ViT / 参考图 VAE / 噪声画布 / 时间步）全部 token 化后 scatter 进同一条序列，80B MoE 主干一体两用：文本位置出文字、图像位置出速度场 v̂，循环 50 步后 VAE 一次译码。

二、核心结论速记

  • 一个主干，两种「头」：文本位置 → ln_f + lm_head（next-token prediction）；图像位置 → final_layer(UNetUp)（flow matching 速度场）。同一次前向可以只走其一（mode="gen_text" / "gen_image"）。modeling_hunyuan_image_3.py:2280-2304
  • 条件注入是 in-context 的：主干 32 层里没有 AdaLN / cross-attention。文本、参考图、时间步全都是序列里的 token。时间步的「调制」只存在于出入口 UNetDown / UNetUp 的 Adaptive GroupNorm 中。modeling:736-756, 1379-1468
  • 占位符 + scatter 的组装方式：tokenizer 先铺好 <img>×N 和 <timestep> 占位，forward 开头用 instantiate_vae_image_tokens / instantiate_vit_image_tokens / instantiate_continuous_tokens 按 mask 原位覆盖。modeling:2170-2202
  • 混合注意力掩码：文本因果、图像段内双向——用一个 4D bool mask 实现，图像 slice 的方块整体置 True。modeling:2859-2884
  • 统一 2D RoPE：文本走对角线 (n,n)，图像段以 β_y=L+(wh−h)/2、β_x=L+(wh−w)/2 为起点铺 2D 网格（居中对齐设计，参考苏剑林方案）。modeling:403-484
  • 扩散采样复用 LLM 推理基建：首步 prefill 整条序列并缓存 KV；之后每个去噪步只前向 [<timestep>] + 画布 token，position_ids 固定，KV 原位覆盖（HunyuanStaticCache.index_copy_）。modeling:2931-3002, 895-970
  • 参考图 = VAE(t=0) + ViT 双路 joint：VAE 路给像素级素材（可被"搬运"），ViT 路给语义；条件 latent 与噪声画布共用同一个 UNetDown，只是时间步不同（t=0 表示干净）。modeling:2426-2454, 1806-1895
  • MoE 细节：门控 Linear 固定 fp32，softmax 后 top-8 归一化加权；1 个共享专家恒开与路由结果相加（use_mixed_mlp_moe）；每专家 SwiGLU 4096→3072。modeling:1092-1254
  • Instruct 特有流程：先 gen_text 出 CoT（think / recaption 改写），可自动生成 <img_ratio_*> 决定画幅，再把 CoT 文本拼回上下文进入 gen_image。蒸馏版另有 <guidance>（CFG 蒸馏）与 <timestep_r>（MeanFlow）token。modeling:3236-3403
