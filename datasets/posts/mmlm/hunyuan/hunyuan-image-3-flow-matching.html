流匹配与时间步 t：噪声怎么一步步变成图像

HunyuanImage-3.0-Instruct 深挖专题 ④ · 理论篇：Flow Matching / Rectified Flow → t 与噪声浓度 → t 的两种注入哲学（对比 Qwen-Image-Edit）→ 50 步演化的逐步解释 · ← 返回总览 · 主干专题 →
全篇主线：生成图像 = 把「噪声分布」搬运成「图像分布」。Rectified Flow 选了最简单的搬运路线——直线：x_σ = (1−σ)x₀ + σε。模型学的是这条线上的速度场 v = ε − x₀；σ（即 t/1000）是「噪声浓度刻度」，决定了此刻画布上什么信息还活着、模型该干粗活还是细活；t 必须作为输入告诉模型，因为最优速度场是随时间变化的。Hunyuan 注入 t 的方式是「1 个 in-context token + 出入口两处 AdaGN」，与 Qwen 的「每层 AdaLN 广播」形成两种哲学。

一、Flow Matching 理论：从「搬运分布」讲起

生成模型的本质任务：手里有一个容易采样的分布（高斯噪声 p₁）和一个想要采样的分布（真实图像 latent 的分布 p₀），求一个变换把前者的样本变成后者的样本。扩散/流匹配的思路：不找一步到位的变换，而是造一条连续演化路径，让样本沿路径流动。

Rectified Flow 的选择：两点之间，直线。随机配对一张真图 latent x₀ 和一份噪声 ε，用比例 σ∈[0,1] 做线性插值：

x_σ = (1 − σ)·x₀ + σ·ε　　（σ=0 纯图像，σ=1 纯噪声）

对这条直线求导，得到它的速度——一个与 σ 无关的常向量：

dx_σ/dσ = ε − x₀　≡　v　　（直线的方向从头到尾不变）

训练目标就是让网络在任意中间点回答出这个方向：

L = E_{x₀, ε, σ} ‖ v_θ(x_σ, σ, 条件) − (ε − x₀) ‖²

每个训练步：取一张真图 → 编码成 x₀ → 随机抽 ε 和 σ → 合成 x_σ → 让模型预测 v → MSE。这正是我们训练脚本里 add_noise / training_target 那几行。

训练在「直线世界」里出题（条件速度恒定、监督信号简单），模型学到的是弯曲的边际速度场（条件期望）。Rectified Flow 之所以叫「拉直」：这样训出的场比 DDPM 的弯路直得多，Euler 少步数就能走好。
三个理论要点（比公式更重要）
  • 为什么这样训是「对的」：Flow Matching 定理（Lipman et al. 2023）——对「条件速度」做回归，得到的恰是「边际速度场」，而沿边际速度场积分的 ODE 能把 p₁ 精确输运到 p₀。翻译成人话：每道题只考一条直线，但把所有题做对的平均，就是那张能走通全程的地图。
  • 与 DDPM 的区别：DDPM 预测噪声 ε̂、路径带随机性（SDE）、噪声调度弯曲；Rectified Flow 预测速度、确定性 ODE、路径笔直。直路径是 Euler 采样少步高效的根源，也是蒸馏（几步出图）的基础。
  • 「预测 v」「预测 ε」「预测 x₀」三位一体：在 x_σ 已知的前提下互相换算——v = ε − x₀，x₀ = x_σ − σ·v，ε = x_σ + (1−σ)·v。选 v 做目标是因为它在各 σ 下数值幅度均衡，训练最稳。

二、σ（噪声浓度）：一根轴上的三个世界

σ 是「噪声浓度刻度」。频率视角解释了为什么去噪天然按「构图→形状→纹理」的顺序推进；shift=3 把 50 步中的大多数分配给高噪区——因为那里的每一步在决定不可逆的构图。
为什么模型必须「知道」t —— 三层理由
  • 数学上：最优速度场是时变的。v(x, σ) 是定义在「位置 × 时间」上的场——同一个位置 x，在 σ=0.9 时被穿过它的直线族和在 σ=0.2 时完全不同，条件期望也就不同。不给 σ，等于让模型解一个不适定问题。
  • 感知上：同一张噪图有歧义。一张灰蒙蒙的 x 可能是「高噪的风景照」也可能是「低噪的雾天照片」——该大刀阔斧还是轻描淡写，只有 σ 能裁决。
  • 工程上：一个网络分饰一整个连续谱的角色。σ 连续变化对应「构图师→造型师→修图师」的连续工种切换；t 就是发给网络的「今日工牌」。这也是训练时 σ 采样分布（logit-normal 偏中段 + shift）重要的原因——工种的课时分配。

t 进入网络前的第一步——正弦编码：标量 t 先被展开成 256 维向量 [cos(t·ω_k) ‖ sin(t·ω_k)]，ω_k = 10000^(−k/128)，再过 MLP 升到 4096。为什么不直接喂标量？一个数字太「瘦」，网络难以从中区分 t=712 和 t=705；多频率正弦把标量变成一组「粗细刻度尺」——低频分量区分大阶段，高频分量区分邻近步——MLP 才有材料加工。这与位置编码同源。

三、t 怎么调制网络：Hunyuan 的三通道 vs Qwen 的每层广播

两种哲学：Qwen（DiT 系）让 t 在每层用 AdaLN 强制介入 120 次；Hunyuan 只在出入口盖两次章，深层的 t 信息靠注意力去「查询」那 1 个 timestep token。

  • 为什么两处 + 一个 token 就够：入口盖章意味着每个画布 token 的初始 embedding 本身就是 t 的函数——深层看到的一切图像特征都已经隐含 t；timestep token 再提供一条显式通道，注意力可按需取用。信息论上 t 只是一个标量，不需要 120 个注入口——DiT 的密集调制买的是「控制力和收敛速度」，Hunyuan 用「主干纯净性 + 权重可继承」换了它。
  • 训练侧的呼应：正因主干无 t 参数，我们的 LoRA 微调（只动注意力+共享专家）不会破坏任何时间调制机制；而训 DiT 类模型时 AdaLN 调制 MLP 通常是必训组件。

四、50 步演化：每一步在数学上到底发生了什么

Euler 步的等价变形——这是理解「逐步成像」的钥匙。模型输出 v̂ 后，由三位一体换算，模型对成品的当前估计是：

x̂₀ = x − σ·v̂　　（「按我现在的判断，成品长这样」）

把 v̂ = (x − x̂₀)/σ 代回 Euler 更新式 x' = x + (σ' − σ)·v̂，整理得：

x' = (σ'/σ)·x + (1 − σ'/σ)·x̂₀

每一步 = 把画布和「当前估计的成品」按比例混合：保留 σ'/σ 的旧画布，掺入 (1−σ'/σ) 的 x̂₀ 估计。三个直接推论：

  • 早期的 x̂₀ 是模糊的「平均图」：高噪时信息少，条件期望把所有可能的图平均掉——x̂₀ 像一团正确构图的色雾。此时步长设计得密（shift=3），每步只掺入一点点，让构图在多次修正中稳定下来。
  • x̂₀ 随步数越来越清晰：每走一步，x 里的真实信号占比升高 → 下一次估计的 x̂₀ 更锐利 → 掺入的内容更有细节。「图像逐渐显影」的本质是 x̂₀ 估计序列的收敛。
  • 如果模型完美且轨迹是直线，x̂₀ 从第一步起就不再变——一步直达。50 步是在为「场是弯的 + 模型有误差」买保险；蒸馏版（8 步）就是训练模型把轨迹进一步拉直。

CFG 在几何上做什么：v̂ = v̂_uncond + s·(v̂_cond − v̂_uncond)。两次前向给出「带条件的方向」与「无条件的方向」，其差是纯粹由 prompt 贡献的方向分量；s=2.5 把这个分量放大——每一步都朝「更贴合文字」的一侧多偏一点。偏太多（s 过大）会把 x 推出训练分布 → 过饱和、烧焦感。

shift=3 的 50 步实际时间表：前 40% 的步数只消耗了 18% 的 σ′ 路程——算力被刻意堆在「不可逆的构图期」。每格的「模型在干什么」由第二节的频率论证支撑。

五、疑点解析（阅读中随时追加）

疑点 ①：必须是 50 步吗？推理时缩到 30 步为什么也行？

不是必须。50 只是 generation_config 的默认值（diff_infer_steps: 50），推理时自由可调（--diff-infer-steps 30）；调度器对任意 N 都成立——linspace(1,0,N+1) + shift 重铺站点而已。真正的问题是步数换质量的曲线：

  • 步数在补偿什么：Euler 每步误差 ≈ 轨迹曲率 × 步长²（「场是弯的，我却直着走」）。场若全直 → 1 步到位；rectified flow 训练把轨迹拉得「相当直但不完全直」→ 收益递减曲线：10→30 步提升明显，30→50 已很微弱，50→100 几乎白花钱。50 = 留足余量的保守默认，30 = 常见性价比甜点（省 40% 的 80B 前向）。
  • 减步数时哪里先坏（频率论证的推论）：30 步——构图基本无损（shift=3 仍保高噪区相对密集），细节略软；15~20 步——高噪区「反复表决构图」的次数不足，出现结构性瑕疵（肢体/数量/文字）；<10 步——基础版明显崩。
  • 想走更低，正道是换蒸馏版：Instruct-Distil 推荐 8 步——MeanFlow 蒸馏让模型学「从 t 到 r 一整段的平均速度」而非瞬时速度（这正是 use_meanflow 与 <timestep_r> token 的用途），把「轨迹弯」的问题在训练时解决，而不是推理时用小步硬扛。
  • 两个正交加速：TaylorCache 不减步数、用泰勒外推跳过部分步的主干前向（50 步调度、~30 步算力）；高阶求解器（heun/kutta）反向操作，多花前向换精度，实践中不如加密步数。

一句话：步数的本质是在为「速度场的残余曲率 + 模型误差」买保险——50 是足额保单，30 是理性折扣，8 步要靠蒸馏改造被保险人。
