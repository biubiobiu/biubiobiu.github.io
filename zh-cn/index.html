技能

Linux

熟悉Linux环境下的常用操作，在Linux环境下搭建深度学习环境、模型训练、模型推理、服务上线。

Python

Python是一种高级，解释，交互式和面向对象的脚本语言。

Git

Experienced with git-based development. Mostly, use Github. Also, have experience in working with GitLab.

Kubernetes

Google开源的一个容器编排引擎，用于管理云平台中多个主机上容器化的应用，它支持自动化部署、大规模可延伸、应用容器化管理。

Docker

为了更好的管理、共享搭建好的环境，在开发机Linux环境下创建、维护Docker镜像，用于开发机上模型训练、推理、部署。

Hive

Hive是建立在Hadoop上的数据仓库基础架构，它提供了一系列的工具，可以用来进行数据提取转化加载，是一种可以存储、查询和分析大规模数据的机制，Hive定义了简单的类SQL查询语言。

TensorFlow

TensorFlow是一个端到端开源机器学习平台，拥有全面灵活的生态系统。可以熟练地在TensorFlow环境下搭建模型、数据处理、模型训练、模型推理、模型部署。

PyTorch

PyTorch是一个开源的Python机器学习库，可以熟练地在PyTorch环境下搭建模型、数据处理、模型训练、模型推理、模型部署。

MxNet

MxNet是一款灵活的深度学习框架，可以熟练地在MxNet环境下搭建模型、数据处理、模型训练、模型推理、模型部署。
